# Mintly Studio — Demo Storefront

A bilingual (English/Arabic) demo storefront built with plain HTML, CSS and JavaScript for learning and preview purposes. No external build tools required.

## Features
- 10 sample digital products and 6 example clothing/accessory products.
- Category filters, search, price sorting, product previews.
- Shopping bag with quantity controls and a 10% demo discount (`DEMO10`).
- Favorites and bag saved in the browser using localStorage.
- English/Arabic with right-to-left layout.
- Responsive layouts for phones and desktops.
- Checkout is a **demo message only**. No money is collected and no real items/files are delivered.

## Open locally
Open `index.html` in your browser. Internet access is optional (the Google Fonts fallback will be used offline).

## Upload to GitHub Pages for a noncommercial demo
1. Extract the ZIP on your computer.
2. On GitHub, open your `mintly-studio` repository, then choose **Add file → Upload files**.
3. Select the files **inside** the extracted folder: `index.html`, `styles.css`, `app.js`, `favicon.svg`, `README.md`, `.nojekyll` (if hidden files aren't visible, you may skip `.nojekyll`). **Do not upload the ZIP as the website.**
4. Click **Commit changes**.
5. Visit **Settings → Pages → Build and deployment** and select **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
6. After deployment completes, your demo link is usually `https://YOUR-USERNAME.github.io/mintly-studio/`.

**Note:** GitHub Pages is intended for sites like project demos/portfolios and is not an appropriate hosting service for operating an ecommerce business or processing commercial transactions. Move to appropriate hosting and add a real platform/payment integration later if you decide to sell products. Fashion previews are illustrative symbols, not real merchandise photos.
